Source code for the bundled ffmpeg

Oculus includes ffmpeg (ffmpeg.exe on Windows, ffmpeg on macOS), a program
the Oculus project built, unmodified, from FFmpeg 8.1.3 with libopus 1.6.1
and dav1d 1.5.4. It is licensed under the GNU Lesser General Public License,
version 3 or later; see FFMPEG-LICENSE.txt. Oculus runs it as a separate
program.

The complete corresponding source code for it is available to anyone, at no
charge, from:

  https://github.com/Tchanwangsa/oculus/releases/tag/ffmpeg-8.1.3-oculus2

That release holds the unmodified FFmpeg, libopus and dav1d source tarballs,
the build script and configure flags used to build ffmpeg (also in the Oculus
repository under app/scripts/ffmpeg/), the full configure lines, the
configure logs and the toolchain versions. FFMPEG-README.txt lists the
SHA-256 of each source tarball and of each ffmpeg binary.

We will keep this source available there for as long as we distribute this
build of ffmpeg. If the link does not work, open an issue at
https://github.com/Tchanwangsa/oculus/issues and we will provide the source
another way.
